# FIRE Simulator ― 全世界株で描く、自由までの道のり

全世界株式のインデックスファンドに積み立てたとき、**何歳でFIREに届くか**、**資産が何歳まで持つか** を、
1871年からの相場の歴史で確かめる無料のシミュレーター。特定の金融商品をすすめるものではありません。

## 起動

`run.bat` をダブルクリック（ブラウザで http://127.0.0.1:8777/ が開きます。`build/serve.py` がキャッシュなしで配信）。
`web/` フォルダはそのまま静的サイトとして公開できます（サーバー側の処理なし）。

## データの更新

`update_data.bat` をダブルクリック（`build/fetch_data.py` → `build/build_data.py` で `web/data.js` を作り直す）。

## データ（公開用：再配布の制約が少ないものだけ）

月次の「円建て・配当再投資・信託報酬（年0.058%）控除後」リターンを、次のデータでつないでいます。

| 期間 | データ | 処理 |
|---|---|---|
| 1990/07〜 | Ken French Data Library 先進国株式市場（USD） | × ドル円 − 信託報酬 |
| 1973/02〜1990/06 | Ken French Data Library 米国株式市場（CRSP, USD） | × ドル円 − 信託報酬 |
| 1926/07〜1973/01 | 同 米国株式市場 | 固定相場の時代なのでドル建てのまま米国CPIで実質化 |
| 1871/02〜1926/06 | Robert J. Shiller の S&P 500（配当込み） | 同上 |

- ドル円：米連邦準備制度理事会 H.10（日次の月末値、米国政府の公表データ）
- 物価：1973/02以降は総務省統計局「消費者物価指数」長期時系列（e-Stat、政府標準利用規約に基づき出典を明記して加工）、それ以前は米国CPI（Shiller のデータ集に収録された BLS の CPI）
- 新興国株（世界の時価総額の約1割）は含まないため、実際の全世界株式ファンドとはリターンが少しずれます
- Ken French と Shiller のデータは明示的なライセンスがなく、出典を明記して研究・ツールで広く使われているものです

使っていないもの：MSCI の指数値（規約で再配布・加工を禁止）、運用会社の基準価額（無断使用を禁止）、
日本銀行の統計（商用目的は要相談）。

## シミュレーションの前提

- 金額は「今の価値」で入力・表示。内部は名目で動かす（NISA枠・税金は名目で効くため）
- **相場の前提**：歴史（過去の各月を出発点に実際の順番で）／ブロック・ブートストラップ（36ヶ月の塊を2,000通り）／想定利回り（対数正規）
- **FIRE**：資産が目標額（生活費×12÷取り崩し率）に届いたら、または指定年齢で辞める。遅くとも「辞める年齢」で辞める
- **取り崩し**：定額（物価連動）／定率（毎年資産の◯%）／ガードレール（取り崩し率が当初の±20%を超えたら生活費を±10%）
- **税金**：特定口座から先に取り崩し、含み益に20.315%。NISA（年360万円・生涯1,800万円、売却分の枠は戻る）は非課税
- 年金・副収入・ライフイベント（一時収入／支出）に対応
- 含まないもの：国民健康保険・住民税の所得割、iDeCo、配当課税、為替ヘッジ、資産クラスの分散（現金・債券）
